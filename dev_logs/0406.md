# Dev Log 2026-04-06: SFT 数据总结 & 多模型蒸馏

## 一、SFT 数据截断方式说明

### 截断方式

| 类型 | 说明 |
|------|------|
| **truncA** | 截断到 best score 那一轮（不包含 final submission） |
| **truncB** | truncA + 继续到包含 `<answer>` tag 的轮次（final submission） |
| **truncAF** | truncA + 人工追加的 FINAL SUBMISSION 轮（best turn 的 exec output + submission 指令 + best turn 代码重复） |

### truncAF 详细说明
- user 消息 = best turn 的执行输出（`<information>...</information>`）+ `[ACTION: FINAL SUBMISSION]` 指令
- assistant 消息 = 原始轨迹最后一轮（如果有 `<python>`），否则复用 best turn 的代码
- 去掉了 `<answer>` tag、`[Step X/Y]`、task memory、cross-task memory、reference approach
- 所有 assistant 消息统一为 V6 格式：只有 `<goal>` + `<python>`
- 连续 user 消息已合并
